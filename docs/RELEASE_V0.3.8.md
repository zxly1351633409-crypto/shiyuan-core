# v0.3.8 发布记录：个人助手默认安装

日期：2026-09-01

## 目标

修正公开仓库安装入口的歧义。首次安装必须创建属于当前用户的空白个人助手，
不能因为仓库包含 company-safe 目录就默认安装“十元·公司安全模式”，也不能把
原作者的助手身份写入别人的 Core。

## 已完成

- 根目录新增默认个人版一键安装器与 Codex 自主安装入口。
- 首次安装支持自定义助手名称；Core、Codex、Hana、记忆 Vault、管理台和在线标记
  使用同一个名称。
- company-safe 改为只有显式选择 Mode Company 才能安装的可选模式。
- 检测到旧公司模式时默认停止；只有 ReplaceCompanyMode 明确给出后才先归档旧状态、
  再安装个人 Core。
- 新增误装公司版的迁移文档。
- 清理公开运行时和工具描述中的固定“十元”身份；保留 Shiyuan 作为项目和接口前缀。
- 旧版默认在线标记在助手改名时自动迁移；用户自定义标记不会被覆盖。
- 更新公司安全包的防篡改清单，使新增入口警告仍可通过完整性校验。

## 验证证据

- Windows PowerShell 5 语法解析通过。
- Python 测试 45 项全部通过，其中包含不提供 Token 时的 PowerShell 5 安全随机生成路径。
- 10 个变更中的 JavaScript/MJS 文件通过 Node 语法检查。
- 公开发布隐私审计通过，没有发现标准私人标记。
- 公司安全包 28 个文件的 SHA-256 清单校验通过。
- Docker Compose YAML 可解析；本机未安装 Docker，因此没有执行镜像构建。
- 临时空白用户目录完成真实 Codex 安装、依赖安装和 Hook 调用；Core 返回“海棠”，
  在线标记为“🐳 海棠在线”，上下文中不再冒充十元。
- 临时空白用户目录完成真实 Hana 安装与消息链路烟测；名称、上下文、历史净化和
  在线标记均通过。
- 真实执行“公司安全版 → 个人 Core”迁移；旧状态进入带时间戳归档，配置只保留
  SHIYUAN_PERSONAL_CORE。

## 未改变

- 现有个人或家庭十元实例不会被本次公开仓库改动自动更新。
- 公司安全版仍保持离线边界，不会连接家庭 Core 或 NAS。
- 公开包仍是空白框架，不包含原作者的画像、聊天、数据库、密钥或私有文件。

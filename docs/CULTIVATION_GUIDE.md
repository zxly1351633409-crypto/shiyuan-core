# 如何培养自己的个人 AI 助手

把 Core 启动起来，只是获得了一个空白的记忆容器。真正的“培养”发生在之后：
你和助手一起工作、纠正它、审核候选记忆，并逐渐把重复做法沉淀成稳定规则。

培养的目标不是让它保存你说过的每句话，而是让它在下一次遇到相似问题时，
能够少问一次、少误解一次，并且知道哪些事情仍需向你确认。

## 先理解四类内容

| 类型 | 保存什么 | 例子 | 是否长期有效 |
| --- | --- | --- | --- |
| 已确认记忆 | 稳定事实、偏好与边界 | “默认用中文回复” | 是，可更新或撤销 |
| 候选记忆 | 尚未确认的推断或新陈述 | “可能喜欢先看结论” | 否，审核后才生效 |
| 工作状态 | 当前目标、进度、证据与下一步 | “部署完成，等待手机验收” | 随任务变化 |
| 程序性知识 | 如何完成一类重复工作 | “每次发布前运行脱敏扫描” | 是，适合写成 Skill 或流程 |

聊天记录是证据来源，不等于已确认记忆。任务回执用于快速接班，也不能替代完整历史。

## 30 天培养计划

### 第 1 周：先让它知道边界

目标：建立一个小而可靠的初始画像，不导入整台电脑。

1. 编辑 Vault 中的 `00 Identity/<你的助手名称>.md`：写清助手的职责、语气和权限边界。
2. 编辑 `00 Identity/用户画像.md`：先写 5～10 条稳定事实。
3. 写出至少 5 条禁止事项，例如不得自行发布、删除、付款或上传私人资料。
4. 每天用它完成一个真实的小任务，观察它在哪些地方误解你。
5. 对重要新结论只提交候选，不要自动确认。

第一周适合记录：语言偏好、常用设备、沟通方式、长期目标、数据边界。

第一周不适合记录：一次情绪、临时任务、未经证实的性格判断、密码和账号凭据。

### 第 2 周：教它怎样与你配合

目标：把“你不喜欢什么”转换成可复用的工作规则。

纠正时尽量包含四件事：

> 以后遇到什么情况 → 应该怎样做 → 为什么 → 怎样才算做对。

例如：

> 以后准备修改项目前，先读取现有进度和历史决定。因为我不希望重复解释，
> 也不希望新修改破坏已经完成的部分。能够准确说出当前状态和下一步，才算恢复成功。

本周结束时，列出全部候选记忆。逐条确认、拒绝或改写；不要为了“更懂你”而全部通过。

### 第 3 周：接入知识与工作流

目标：让助手不仅认识你，还能帮助你做事。

1. 只选择一个低敏感资料源，例如一个 Obsidian 文件夹或一组公开项目文档。
2. 保留来源、日期和原始文件位置，使检索结果能够回到证据。
3. 选择一项每周都会重复的工作，把步骤、输入、输出和验收标准写成流程。
4. 让助手完整执行一次，再根据真实结果修改流程。
5. 稳定后再接入第二个资料源，不要一次灌入所有文件。

这一步的完成标准不是“索引了多少文档”，而是它能否找到正确资料，并用资料完成一个真实任务。

### 第 4 周：测试连续性

目标：确认它换会话、换设备或换 Agent 后仍然是同一个助手。

至少进行四次测试：

1. 在身体 A 中提交并确认一条新偏好，再让身体 B 自然应用。
2. 在身体 A 中开始任务并保存检查点，再让身体 B 继续下一步。
3. 在身体 B 中纠正一条工作规则，再检查身体 A 的新会话是否生效。
4. 模拟 Core 暂时离线，确认身体不会假装已经读取或写入记忆；恢复后检查离线补传。

如果只能复述画像，却不能正确承接工作，不算培养完成。

## 推荐的日常节奏

- 每天：正常使用。出现明显误解时，给出一条带原因的纠正。
- 每周：审核候选记忆，清理过期任务，挑一条重复劳动改成流程。
- 每月：检查过期事实、冲突规则、权限边界和备份恢复能力。
- 每季度：重新回答“它现在替我减少了什么负担”，没有实际效果的功能可以停用。

## 可以直接使用的对话方式

```text
这是长期偏好，请先作为候选记忆，不要替我确认：……
```

```text
这只是本次任务的临时要求，不要写入长期记忆：……
```

```text
列出最近的候选记忆，并说明每条的来源；先不要确认。
```

```text
确认候选记忆 <ID>。依据是：……
```

```text
以前遇到过类似问题。请先恢复相关决定、当时的理由和当前状态，再回答。
```

```text
把这次工作的目标、进度、决定、产物、证据和下一步保存为接续回执。
```

## 一个月后的验收问题

不要问“你了解我吗”，而要用能验证的题目：

- 我明确确认过的三项偏好是什么？来源在哪里？
- 哪些只是候选，不可以当成事实？
- 最近一个未完成任务做到哪里，下一步是什么？
- 我曾否决过什么方案，为什么？
- 换到另一个已接入身体后，能否继续同一任务？
- Core 离线时，它是否诚实说明知情范围？
- 我要求删除或纠正一条记忆后，旧结论是否还会被使用？
- 检索结果能否回到原始证据？

建议把结果记录下来。下一月与本月比较，关注误召回、遗漏、重复确认和任务承接成功率，
而不是只关注记忆数量。

## 最容易踩的坑

- 一开始扫描整台电脑，导致噪声、隐私风险和错误画像同时增加。
- 把所有候选自动确认，让一次随口表达变成永久事实。
- 只调人格和语气，却没有任务状态、证据和工作流程。
- 把短摘要当成完整历史，后来找不到决定发生变化的原因。
- 多个 Agent 直接修改同一份记忆文件，没有统一 Core、版本和冲突规则。
- 只做演示问题，不用真实任务检验它是否减少了你的负担。

一个健康的个人 AI 会越来越熟悉你，但不会越来越武断。它应该记得该记的，
承认尚不知道的，并把重要决定留给你。

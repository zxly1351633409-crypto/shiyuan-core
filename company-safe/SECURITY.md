# 安全声明

- 本包默认不连接家庭或公网服务，也不包含任何人的 Token、API Key、消息平台 Webhook 或历史数据。
- 完整记忆指“完整已确认抽象记忆快照”，不是家庭数据库、原始聊天、文件正文、候选记忆或向量索引的复制品。
- 公司本地增量记忆保存最多 300 字的候选结论与审核元数据；跨身体工作保存不超过 900 字的用户可见检查点/结果摘要、决策、产物、证据和下一步。
- Codex/Hana 的用户消息与助手可见回复会作为本地会话转录保存在 `%USERPROFILE%\.shiyuan-company\state\history`，用于历史召回与跨身体接续。密码、Token、API Key、私钥在落盘前脱敏。
- Codex 可见活动桥只尾读新追加的 `response_item/message`，并同时要求 `role=assistant` 与 `phase=commentary`；首次启动从每个既有文件 EOF 建立位置，不重放公司旧会话。偏移、锁和错误日志只保存在公司本地 state 目录。
- 知情范围账本只统计本机元数据、数量和时间，不包含对话正文、源文件路径、凭据或私有推理。
- 不保存模型私有推理、隐藏系统提示、工具原始输出、文件正文、剪贴板或屏幕；不自动上传公司本地状态。
- 自动提取使用保守确定性规则，不调用额外模型，不连接网络；误判和漏记仍可能发生，因此 candidate 不能当作事实。
- 公司 Codex 的自助安装授权仅覆盖当前用户目录下的低风险、可回滚安装；不得绕过公司策略或管理员限制。
- 本包不保证某段公司信息可以合法或合规地带离公司；人工审核和公司制度优先。
- `safe_summary` 只是 Agent 的初步分类，不是合规批准。
- 密钥样式检测只能拦截常见文本模式，不能识别所有商业秘密。
- 企业微信自发消息仍属于数据传输；若公司不允许，交接卡必须留在公司本地。
- 安装前应核对 ZIP 的 SHA-256，并检查 `install.ps1`、Hook 与 MCP 源码。

# 十元公司安全版 v0.1.8

> 可选专用模式，不是默认个人版。只有组织制度明确要求完全离线、且用户主动
> 选择公司安全模式时才安装。普通个人助手请使用仓库根目录 install.ps1。

这是给 Windows 公司电脑准备的离线边缘安装包。它让 Codex/Hana 使用十元的交流方式与交接格式，并在公司电脑本地形成、审核和召回短候选记忆，共享结构化工作状态，并归档双方可见的对话文本；默认不连接家庭 NAS，也不自动上传任何内容。

公开模板携带的是空白静态记忆文件，不包含任何人的画像、原始对话或部署信息。部署者只有在符合组织制度并完成审核后，才能写入自己的抽象记忆；静态快照不会冒充实时同步。

如果用户希望由公司 Codex 自行安装，请把解压后的目录交给 Codex，并让它首先阅读 `START_HERE_CODEX.md`。Codex 会检查脚本、验证文件清单、执行安装并留下报告；用户只需在完成后重启应用并新建会话。

## 安全模型

- 公司端标记固定为 `🐳 十元·公司安全模式`，不会冒充家庭 Core 在线。
- Codex 与 Hana 共用 `%USERPROFILE%\.shiyuan-company\state`，保存自动提取的短候选、人工审核状态、已确认本地记忆、可见对话文本、工作检查点和结构化回执。
- 公司 Codex 会在本机启动单实例“可见活动桥”，从现有会话文件末尾增量读取 `assistant/commentary`，把正在进行的可见阶段更新写成公司本地检查点。桥不读取旧会话全文，不连接网络；`reasoning`、系统/开发消息、工具调用和工具输出会被硬排除。
- 每轮会注入公司本地“知情范围与新鲜度”账本，明确可见历史来源、确认/候选记忆、活跃/过期工作和最近活动身体；未接入内容不会冒充已知。
- 可见对话只留公司本机，用于“以前那个”“继续刚才的”和跨身体接续；已知密码、Token、API Key、私钥会在落盘前脱敏。
- 不归档模型私有推理、隐藏系统提示、工具原始输出、屏幕、剪贴板或文件正文；也不自动连接家庭 Core、NAS、企业微信或云盘。
- 明确偏好、习惯和“请记住”类陈述可以自动成为 candidate；疑问句、密钥、链接、邮箱、内部路径和明显保密线索会被保守拦截。
- 候选不会自动确认。只有用户明确要求后，Agent 才能调用审核工具；确认后的内容才会在后续会话中召回。
- 只有用户明确要求“生成交接卡”时，Agent 才调用本地工具。
- 工具仅接收 Agent 已经整理好的摘要、决策和下一步，不读取完整会话历史。
- 交接卡先保存到 `%USERPROFILE%\Documents\十元交接箱`，状态为“等待人工审核”。
- 用户必须检查公司制度、商业秘密、他人信息与附件路径后，才能手动发送。
- 安装包不含外部服务地址、Core Token、消息平台 Webhook 或任何私人凭据。
- `confirmed-memory.md` 与 Hana 内置副本必须一致，且只包含已确认抽象内容。

## 安装

先取得公司 IT/安全制度允许，再在 PowerShell 中运行：

```powershell
.\install.ps1
```

仅安装某一个身体：

```powershell
.\install.ps1 -Codex
.\install.ps1 -Hana
```

Codex 安装会备份 `~/.codex/config.toml`，并追加带边界标记的配置块。首次启动新任务时，Codex 可能要求你信任新 Hook；应核对命令确实位于 `~/.shiyuan-company/codex` 后再批准。

Hana 安装优先使用正在运行的 Hana Server 本地安装接口；若 Hana 未运行，则复制插件，重启 Hana 后加载。两个身体都安装时，共享同一个公司本地记忆目录，因此在 Codex 中确认的本地候选也可被 Hana 召回，反之亦然。

## 审核公司本地候选

你可以直接对 Codex/Hana 说：

> 列出十元公司本地候选记忆。

看到内容后，再明确说“确认第几条”或“拒绝第几条”。确认只改变公司电脑本地状态，不会上传家庭 Core。

## 生成并带回交接卡

在公司对 Codex/Hana 明确说：

> 生成十元公司交接卡。只写允许带回家的抽象摘要，不包含原文、附件、账号、内部路径和未公开名称。

Agent 会调用 `export_shiyuan_company_handoff`，产生 `.json`、`.md` 和适合人工复制的 `.txt`。先阅读 `.md`，确认合规后，才能把 `.txt` 内容或经过批准的 `.json` 文件通过企业微信发给自己。

回到家后使用：

```powershell
python .\home-import\import_company_handoff.py --file "交接卡.json"
python .\home-import\import_company_handoff.py --file "交接卡.json" --approve-reviewed --create-task
```

第一条命令只预览；第二条才把脱敏摘要写入十元 Core，并按需创建任务卡。

## 卸载

```powershell
.\uninstall.ps1
```

卸载不会直接删除数据：Codex/Hana 组件和交接箱会移动到带时间戳的停用归档目录。重启 Codex/Hana 后生效。
